# Strategy Frameworks

## SWOT

Use for strategy, positioning, and direction setting when both internal and external factors matter.

Ask:

- What internal strengths are real and defensible?
- What weaknesses limit execution?
- What external opportunities are emerging?
- What threats could reduce the opportunity?

Output:

| Quadrant | Analysis |
| --- | --- |
| Strengths |  |
| Weaknesses |  |
| Opportunities |  |
| Threats |  |

Then derive:

- SO strategy: use strengths to capture opportunities.
- WO strategy: fix weaknesses to capture opportunities.
- ST strategy: use strengths to defend against threats.
- WT strategy: reduce exposure.

## PESTLE

Use for macro environment analysis.

Dimensions:

- Political
- Economic
- Social
- Technological
- Legal
- Environmental

Ask for each dimension:

- What is changing?
- Why does it matter?
- What evidence supports it?
- What should the product/business do?

## Porter Five Forces

Use for industry attractiveness and competitive pressure.

Forces:

- Competitive rivalry.
- Threat of new entrants.
- Bargaining power of suppliers.
- Bargaining power of buyers.
- Threat of substitutes.

Avoid making claims about force intensity without evidence. Mark intensity as `待确认` if not known.

## Scenario Planning

Use when uncertainty is high and a single forecast is fragile.

Steps:

1. Identify 2 critical uncertainties.
2. Build 3-4 plausible scenarios.
3. Analyze implications and early signals.
4. Define robust actions that work across scenarios.
