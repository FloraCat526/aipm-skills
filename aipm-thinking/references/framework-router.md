# Framework Router

Choose the framework based on the job the user needs done, not based on keyword matching alone.

## Routing Table

| User need | Primary frameworks | Good when | Avoid when |
| --- | --- | --- | --- |
| Form strategy | SWOT, PESTLE, Porter Five Forces, scenario planning | External environment, competition, positioning, uncertainty | User only needs task planning |
| Design business model | Business Model Canvas, Value Proposition Canvas, unit economics | Revenue, customers, channels, costs, value proposition | No commercial model is involved |
| Understand product opportunity | JTBD, user journey, Kano | User needs, product value, feature fit | Problem is purely operational |
| Prioritize work | RICE, ICE, MoSCoW, Kano | Feature backlog or roadmap trade-offs | Inputs are too vague to score |
| Diagnose root cause | 5 Whys, fishbone, causal loop | A recurring problem or failure | The user needs future planning, not diagnosis |
| Assess risk | Risk matrix, premortem, scenario planning | Launch risk, strategy risk, project risk | Risks are already known and only need execution tracking |
| Align stakeholders | Delphi, DACI, RACI | Expert consensus, decision rights, ownership ambiguity | One person can decide directly |
| Decompose complexity | MECE, first principles, systems thinking | Ambiguous complex problem | User needs a simple checklist |

## Selection Rules

- Use one framework for a narrow question.
- Use two complementary frameworks when one frames the problem and the other drives action.
- Do not use more than three frameworks unless the user asks for a workshop plan.
- If the user asks "what should I do", include a decision or next-step section.
- If key facts are missing, ask before scoring or comparing.

## Common Combinations

- Strategy under uncertainty: PESTLE -> SWOT -> scenario planning.
- New product idea: JTBD -> Value Proposition Canvas -> RICE.
- Business viability: Business Model Canvas -> unit economics.
- Feature prioritization: Kano -> RICE.
- Persistent failure: 5 Whys -> fishbone -> action plan.
- High-risk launch: premortem -> risk matrix -> mitigation plan.
- Stakeholder conflict: DACI -> Delphi if expert consensus is needed.
